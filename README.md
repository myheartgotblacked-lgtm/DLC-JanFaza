# 🛡️ DLC JanFaza

### Windows Security Status Monitor

DLC JanFaza is a lightweight Windows desktop application designed to help users monitor their Windows security status through a simple and user-friendly graphical interface.

Built with Python and Tkinter, this project provides quick access to important Windows security information and settings.

---

## ✨ Features

- 🛡️ Windows Defender status monitoring
- 🔍 Real-time protection status checking
- 🔐 Antivirus status monitoring
- 👁️ Antispyware protection monitoring
- 📊 Simple security status overview
- ⚙️ Quick access to Windows Security
- 🔥 Quick access to Windows Firewall settings
- 🖥️ Lightweight graphical interface
- 📦 Support for standalone Windows EXE builds

---

## 🖥️ Requirements

- Windows 10 or Windows 11
- Python 3.10 or newer
- Tkinter
- PowerShell
- PyInstaller (for EXE builds)

---

## 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-myheartgotblacked-lgtm/DLC-JanFaza.git
```

### 2. Open the project folder

```bash
cd DLC-JanFaza
```

### 3. Run the application

```bash
py DLC_JanFaza.py
```

---

## 📦 Build EXE

Install PyInstaller:

```bash
py -m pip install pyinstaller
```

Build the executable:

```bash
py -m PyInstaller --onefile --windowed --name DLC-JanFaza DLC_JanFaza.py
```

The executable will be available in:

```text
dist/DLC-JanFaza.exe
```

## 🔒 Security Notice

DLC JanFaza is designed for security monitoring and convenience.

- It does not intentionally disable Windows Defender.
- It does not modify Windows security policies.
- It does not bypass antivirus protection.
- It only reads available security status information and opens Windows settings.
